# The Command Line

The `vys` command line utility is responsible for collecting and visualizing
`project.vys` and `module.vys` files across the repository, beginning either
from the directory it's executed or from `--project-root`.

The `vys combine` command produces a combined top level form, using the `within`
form to change the working location within the dependency tree.

```scheme
(vys-project
    (module ...)
    (module ...)
    (module ...)
    (within (. foo)
        (module ...)
        ...))
```

The `vys graph` command produces a Graphviz graph, either from the directory
it's executed from, a root specified with `--project-root`, or `--stdin`.
`--stdin` accepts the output of `vys combine`.

`vys materialize <MODULE...>` produces another format, specifying read-only and
read-write access for the given modules:

```scheme
(vys-manifest
    (ro "file.txt" "directory/" "some/subdirectory/")
    (rw "another-directory/" "something.c"))
```

`vys sandbox [--from-file=<FILE>|--stdin] bubblewrap -- [ARGS...]` consumes a
`vys-manifest` form to spin up a bubblewrapped agent.
